# 📋 Gerenciador de Tarefas em Java

Este é meu primeiro projeto desenvolvido em **Java**, utilizando o Visual Studio Code (VS Code).

O objetivo deste projeto é praticar lógica de programação e desenvolver meus conhecimentos na linguagem Java, por meio da criação de um sistema simples de gerenciamento de tarefas.

## 🚀 Funcionalidades

- ➕ Adicionar novas tarefas.
- 📋 Listar todas as tarefas cadastradas.
- ❌ Excluir tarefas.
- 🚪 Encerrar o programa pelo menu.

## 🛠️ Tecnologias utilizadas

- **Java 21**
- **Visual Studio Code (VS Code)**

## 📚 Conceitos de programação utilizados

Durante o desenvolvimento deste projeto, pratiquei:

- `Scanner`: entrada de dados pelo teclado.
- `ArrayList`: armazenamento dinâmico das tarefas.
- `do-while`: repetição do menu principal.
- `switch-case`: seleção das opções do sistema.
- `for`: percorre e apresenta a lista de tarefas.
- `if-else`: verificação das opções e validação dos dados.

## ▶️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o terminal na pasta onde está o arquivo `Main.java`.
4. Compile o programa:

```bash
javac Main.java
```

5. Execute:

```bash
java Main
```
